SCAMP 式飞行攀爬机器人与双模态双稳态足端方案构想

📝 阶段：文献调研与初步机构构想 🎯 目标平台：Crazyflie 2.1 无刷版量级 📅 整理时间：2026 年

写在前面：本项目属于学术文献深度精读后的机构方案设计与概念验证尝试。飞行平台直接参考 Stanford 经典的 SCAMP 路线，核心构想聚焦于如何在极严格的质量预算（10-15g）下，通过双稳态薄板与 SMA 脉冲驱动，实现粗糙表面微刺与光滑表面干黏附的两模式高效切换与断电自保持。

一、 核心构想：双稳态薄板足端

Mode 1（粗糙表面） Mode 2（光滑表面） ) 形 ( 形 两端朝向墙面 中段朝向墙面 微刺/勾爪咬合粗糙凸点 柔性干黏附垫贴合光滑表面

Mode 1（")" 形 · 粗糙面微刺）

  • 薄板两端向墙面凸出，端部集成小尺寸微刺阵列；
  • 靠微刺与粗糙表面凸起（asperities）发生机械互锁挂住，无需持续消耗电机法向预压力；
  • 具备剪切敏感特性：向下受剪切载荷时牢牢咬合，反向卸载后轻松松开脱附；
  • 设为默认初始稳态，撞墙接触时更抗冲击。

Mode 2（"(" 形 · 光滑面干黏附）

  • 薄板中段向墙凸起，内侧贴附柔性干黏附垫（早期可用 PDMS/PU 膜验证）；
  • 黏附垫上部充分贴合墙面，下端随薄板曲率自然保留弯曲弧度，形成天然的应力集中起剥点；
  • 攀爬臂向上抬起时，从下端应力集中处发起剥离波，实现快速低阻力脱附。

模式切换机制 (SMA 脉冲驱动)

采用 SMA 形状记忆合金丝：通电毫秒级脉冲引发热致收缩，克服薄板 snap-through 跳跃翻转能垒进入另一稳态，随后立即断电。切换后由薄板弹性自保持，彻底避免了 SMA 响应慢和持续发热对攀爬速度回路的影响。

二、 已定工程约束与设计边界

约束项 指标预算 设计依据
飞行平台 Crazyflie 2.1 Brushless 裸机 ~32g，推荐有效载荷预算 ~40g 内
足端与驱动质量 单足端 1-3g，双足+驱动 < 15g 保证微型四旋翼有足够的起飞与机动推重比
攀爬臂尺寸 单臂 35-55 mm SCAMP 式两侧攀爬臂，先做单侧实验台架测试
验证表面 粗糙：80/100目砂纸与混凝土；光滑：玻璃/亚克力 高反差对照测试微刺与干黏附性能边界

三、 当前面临的主要技术挑战与后续规划

  1. SMA 行程与薄板翻转能垒匹配：确保极短 SMA 收缩行程足以越过 snap-through 临界点；
  2. 非优选方向脱附阻力 Anp 抑制：防止摆动足反向拖拽时黏附垫拖滞墙面导致掉落；
  3. 下一步实验计划：先不盲目飞真机，优先在实验室搭设垂直双材料测试导轨，对双稳态足端进行静态加载、动态翻转及力传感器阶跃响应测试。
