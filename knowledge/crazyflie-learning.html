Crazyflie 飞控学习路线：从 Brushless 入门到控制链路

Bitcraze · Crazyflie 2.1 Brushless · Firmware更新于 2026.09.10

当前状态：已看完 Crazyflie 2.1 Brushless 入门教程。现在先建立飞控全链路概念，再沿官方文档进入固件源码；暂不急着修改控制器或刷写飞行器。

这一阶段要弄懂的主线是：传感器 → 状态估计 → Commander 目标值 → 控制器 → 电机分配 → 电机输出。官网文档用来建立地图，官方代码库用来确认这些模块在程序里如何连接。

当前进度 官网学习顺序 官方代码库 阶段目标

01 / 当前进度与学习边界

状态内容学到什么程度
已完成Crazyflie 2.1 Brushless 入门教程认识平台组成、基本操作和安全起步要求。
正在学习Sensor to control 飞控主链路能用自己的话解释各模块的输入、输出和调用关系。
下一阶段连接、参数、遥测和日志知道 cfclient 与 cflib 分别解决什么问题，并保存第一份可复查日志。
之后再做修改控制逻辑与整机实验先建立飞行基线，再为接触、附着和离墙设计状态与观测量。

02 / Bitcraze 官网：按这条顺序学习

STEP 0 · 已完成

Crazyflie 2.1 Brushless 入门教程 ↗

认识 Brushless 平台、首次使用步骤和基本安全要求。它回答“这架飞行器怎么开始用”。

STEP 1 · 当前重点

Sensor to control 总览 ↗

建立从传感器数据到电机输出的全局地图。先看懂模块关系，不需要一开始就钻进每个函数。

STEP 2

State estimators 状态估计 ↗

理解传感器测量如何变成姿态、速度和位置估计；先分清姿态估计与位置估计各自依赖什么信息。

STEP 3

Commanders 与 Setpoints ↗

理解“飞行器现在是什么状态”和“希望它达到什么状态”的区别，以及目标值从哪里来、失联后如何处理。

STEP 4

Controllers 控制器 ↗

学习姿态环、位置环和 PID 等控制器如何把状态误差变成推力与转矩指令，重点看输入、输出和级联关系。

REFERENCE · 需要时查

Building and flashing ↗

学习固件配置、编译产物和刷写方法。本项目使用 Brushless 对应的 cf21bl_defconfig；真正刷写前需先确认硬件与固件目标。

03 / 官方代码库：分别在什么时候看

代码库对应知识现在的优先级
crazyflie-firmware ↗ 机载固件主库。用来对照 stabilizer、状态估计、Commander、控制器、电机分配与电机输出的真实实现。 最高：跟着 Sensor to control 文档读。
crazyflie-lib-python ↗ Python 上位机通信库。用于连接 Crazyflie、读取日志变量、修改参数和编写实验脚本。 第二阶段：开始做连接与日志时看。
crazyflie-clients-python ↗ 官方 cfclient 图形客户端。用于扫描连接地址、查看实时遥测、参数和基本飞行状态，也能参考 GUI 如何调用 cflib。 第二阶段：接真机和检查遥测时看。

当前只需要重点打开两个入口：Sensor to control 总览和 crazyflie-firmware。每读懂一个模块，再进入对应专题页和源码，不需要同时通读三个仓库。

04 / 本阶段完成标准

  1. 画出 Crazyflie 从传感器到电机输出的模块框图。
  2. 解释 state、setpoint、control 三类数据各表示什么。
  3. 在固件仓库中找到主稳定循环，以及状态估计器、Commander 和控制器的入口。
  4. 说明 PID 控制器输出如何进一步变成四个电机的指令。
  5. 完成以上四点后，再进入 cfclient / cflib 的连接、参数和日志学习。
