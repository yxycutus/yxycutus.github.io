校企合作 · Aloha Mini 开源双臂移动机器人调测与遥操作实践

👤 角色：电子组 / 软件组成员 🔗 开源仓库：liyiteng/AlohaMini ↗ 📅 实践周期：2026 春季（已结项完成）

项目概述：Aloha Mini 是一套低成本开源双臂移动操作机器人平台，配备垂直升降导轨与双机械臂系统。在本次校企合作研发项目中，我作为电子组 / 软件组成员，主要负责树莓派系统调试、通信链路贯通、Joy-Con 遥操作适配以及示教数据集采集。

一、 核心工作与职责切分

1. 树莓派底层系统与环境部署

  • 负责树莓派（Raspberry Pi）操作系统的刷写、网络环境配置与驱动配置；
  • 解决板载 CAN / USB 转串口模块与各电机驱动板之间的底层硬件通信稳定性问题；
  • 在 Ubuntu 系统下，通过 SSH 密钥对打通了 主机电脑（开发/推断） → 树莓派（车载工控/执行） → 机器人执行机构 的远程控制与状态监控链路。

2. 基于开源代码实现遥操作 (Teleoperation)

  • 深入研读并跑通 Aloha Mini 开源控制代码，完成主从臂关节电机的角度映射与闭环响应优化；
  • Nintendo Switch Joy-Con 手柄适配：通过蓝牙连接与按键事件映射，实现了用 Joy-Con 摇杆平滑控制移动底盘的平移旋转，以及按键控制垂直导轨升降与末端夹爪开合，极大提升了机器人移动示教与现场搬运测试的便携度。

3. 示教数据集采集与具身智能任务闭环

  • 协同 AI 组同学设计实验采集方案，利用手柄及主手遥操作设备进行大量动作示范；
  • 规范采集多视角机载摄像头图像流（RGB-D）以及关节电机角度/速度时序数据，完成示教数据集的清洗与打包；
  • 为后续模仿学习与行为克隆模型训练提供高质量数据支撑。最终真机部署模型后，成功实现了机器人基于视觉检测识别特定物体后的自主平滑抓取与定点放置（Visual Object Pick-and-Place）。

二、 关键技术细节与问题排查

# 通信与控制拓扑架构简图 [ 操作员主机 (Ubuntu) ] │ (Wi-Fi / SSH 远端节点) ▼ [ 车载树莓派 (Raspberry Pi) ] ── (USB/Serial/CAN) ──> [ 双臂电机伺服驱动板 ] ▲ [ 底盘驱动 & 升降电机 ] │ (Bluetooth HID) [ Joy-Con 手柄遥控输入 ]

在调试过程中，主要攻克了手柄蓝牙输入延迟突增、多路 USB 相机带宽冲突导致数据掉帧、以及多电机连续供电下的通信丢包问题。通过重写串口读取缓存逻辑与优化线程调度，保证了数据采集中控制指令的硬实时性。

四、 收获与思考

通过这个校企合作项目，我从真实的工程现场切身体会到了机器人在物理世界落地的全链路：从底层的强弱电走线、树莓派 Linux 系统调试，到控制链路搭建与遥操作数据流打通。它让我认识到，具身智能模型的效果高度依赖于底层硬件的可靠性与示教数据的干净程度。
