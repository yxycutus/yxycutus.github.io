## 本地预览与更新

### 科哞哞网页陪伴

全站 32 个页面共用 `assets/pet.js` 和 `assets/pet.css`。科哞哞根据所在页面与正在浏览的章节自动陪伴，不需要访客选择动作。

- **主动陪逛**：进入页面时简短欢迎；下滑到项目、笔记、学习、联系等内容时介绍当前章节，部分气泡可直接带去相关页面。同一章节每次访问只介绍一次，两条介绍至少间隔 7 秒；快速划过不会排队播放过时内容。
- **自动待机**：首页先挥手欢迎，再眨眼与视线跟随；知识库翻书，项目页点示清单，课程页写字，关于页指向人物卡片，时间线用小喇叭提示，另有成果喝彩、招募邀请和托腮思考。九组动作使用「网站演示/动作轻动画」中已对齐的透明关键帧与原定时序，每轮约 3—3.34 秒，末尾静止约 2 秒。不叠加整张图片上下漂浮。鼠标或触屏拖动时奔跑，松手跳跃后恢复当前章节动作；页面脚本未捕获错误触发短暂大哭。
- **直接导航**：点击角色立即显示推荐去处、首页、知识库、时间线、关于、搜索和当前页路标；不显示动作选择器。
- **小设置**：导航底部展开「科哞哞设置」，调整大小、首页眼睛跟随、沿途介绍、待机动画，或回到角落、暂时收起。关闭再打开面板时默认回到导航。

同一浏览器记住位置、大小、开关与收起状态；造型随页面自动决定，不沿用旧版的手动选择。支持方向键移动、Esc 关闭面板。暂停保持当前画面，减少动态偏好显示首帧，后台标签停止播放。切换前先解码新动作，等待期间保留旧画面，并预取接下来一个章节的动作；过期请求不会覆盖后来的动作或打断拖动。存储被禁用时仍可操作，主动画图集加载失败可重试；单组动作加载失败先退回透明静态造型。

网页素材位于 `assets/pet/`。新动作使用 `motions/` 中九张按内容哈希命名的透明 WebP 图集，合计约 2.81 MB，按需加载并缓存；Canvas 按原时序显示其中的 512px 关键帧。`motions/manifest.json` 记录时序、源文件 SHA-256 与排除帧；找导师的重复手套错误帧（源索引 1）不参与导入和播放。原素材仅有少量独立关键帧，本次没有把视频输出帧率当成独立绘制帧率。

重新导入：`node scripts/prepare_pet_motions.cjs --source "动作轻动画目录"`（需要 sharp，可用 `SHARP_MODULE` 指定已安装模块）。导入只读取源目录并生成网页专用图集，不执行素材包的脚本，也不复制不透明 MP4。`cutouts/*.webp` 保留为加载失败时的透明静态回退；`scenes/` 为带底色的原画参考副本，不作为桌宠显示。原有奔跑、跳跃和视线图集仍使用 1536×2288、8 列 11 行规格；`scripts/compress_pet.py` 会校验规格，避免裁切错位。

现有页面功能可主动触发反馈，例如：

```js
document.dispatchEvent(new CustomEvent('cutus:pet', { detail: { state: 'failed' } }));
document.dispatchEvent(new CustomEvent('cutus:pet', { detail: { scene: 'achievement', duration: 4000 } }));
```

修改桌宠 JS/CSS 后运行 `node scripts/version_theme_assets.cjs`，刷新所有页面的缓存版本。启动 HTTP 服务后执行 `node scripts/check_pet.cjs` 和 `node scripts/check_pet_motions.cjs` 做真实浏览器验收：前者覆盖全站交互，后者检查九组动作的实际像素变化、循环停顿、透明度、暂停和加载竞态。支持 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`BASE_URL`，截图与报告写入被忽略的 `.preview/pet/`。当前仅做本地预览，发布需另行执行。

首页首屏显示总体进度，首页面板和 `knowledge/crazyflie-learning.html` 共用 `assets/flight-roadmap.js` 的十阶段路线。点击阶段查看官网、步骤与验收产物，拖动滑杆记录百分比。100% 表示产物已验收，不只是读完网页。

- 当前浏览器自动保存百分比与文字笔记，刷新恢复，同源标签页同步；旧版 `cutus-cf-progress` 自动迁移到 `cutus-cf-progress-v2`。
- 导出备份包含进度与笔记；导入会校验格式并在替换前确认。存储失败会显示提示，此时应导出备份。

- 网站是静态 GitHub Pages，没有身份认证和写入后端。拖动不会自动提交仓库。浏览器已有本地记录时优先展示本地记录；无本地记录的访客默认读取公开版本。清理浏览器数据前先导出备份。

用 HTTP 服务预览，以保证首页、详情页共享同一来源的存储并正常读取公开 JSON；不要依赖 `file://` 的浏览器存储行为。
