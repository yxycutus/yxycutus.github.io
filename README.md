# Cutus's Personal Homepage — USTC Robotics Engineering

> **中国科学技术大学 (USTC) 机器人工程 · 专属工科工程设计美学主页**
> 告别千篇一律的单调黑白线性模板，以**中科大官方蓝 (`#004182`)** 为品牌核心基底，结合现代工科 Bento Grid（便笺网格）与机器人系统遥测（Telemetry）视觉元素打造。

---

## 视觉与结构特色

1. **科大蓝品牌视觉体系 (USTC Blue Spectrum)**：
   - 官方标准科大蓝 (`#004182`) + 电光蓝 (`#0284c7`)，搭配清爽的工科微米网格背景 (`bg-grid-pattern`)。
   - 深浅色双主题无缝适配：浅色清爽硬朗，深色（深邃太空蓝黑 `#090d16`）极客感十足。
2. **专属字体架构**：
   - 标题与正文：`Plus Jakarta Sans`（国际顶尖科技感无衬线几何字体，告别 Inter 的千篇一律）。
   - 代码与参数：`JetBrains Mono`（清晰的工科等宽字体）。
3. **彻底重构的页面结构**：
   - **分屏式 Hero**：左侧个人定位与行动入口，右侧独创**机器人遥测面板（System Telemetry）**，实时展示在读节点与技术栈。
   - **Bento 核心领域网格**：4 个工科专属方向（运动学控制、具身智能、嵌入式通信、USTC 专业课体系）。
   - **精选项目独立卡片展台 (Selected Projects)**：专为机器人项目（仿真、下位机、视觉）设计的卡片与标签。
   - **双流状态区 (Dual Stream)**：左侧为当前正在进行（NOW），右侧为最新动态记录（RECENT）。
   - **关于我 (`/about`)**：加入 USTC 机器人工程专用的「技术与工具谱系图」。
   - **知识库 (`/knowledge`)**：支持即时关键词检索与多学科分类筛选。
   - **时间线 (`/timeline`)**：学期阶梯式里程碑与呼吸灯实时状态。

